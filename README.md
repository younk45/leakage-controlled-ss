# Leakage-Controlled Scale-Aware Software Effort Estimation

This repository is the versioned reproducibility package for IJIES manuscript 20265081:

> **Availability-Audited Evaluation of Scale-Aware Software Effort Estimation: A Fold-Isolated Reanalysis**

It reproduces the reviewer-revision analysis on the China Software Effort Estimation Dataset. The protocol explicitly separates predictors by when they could be known, isolates every learned operation inside the outer training fold, preserves full-precision outputs, and uses one shared deterministic project-bootstrap index matrix for all reported confidence intervals.

## Scope

- Primary predictors (`strict6`): `AFP`, `Input`, `Output`, `Enquiry`, `File`, and `Interface`.
- Temporal-provenance sensitivity (`uncertain9`): the primary six plus `Added`, `Changed`, and `Deleted`.
- Deliberately leaky diagnostic (`leaky14`): the uncertain set plus five effort-derived fields.
- Scale scenarios: Global, Global + mutual information (MI), training-fold AFP quantiles, and training-fold AFP quantiles + MI.
- Modern benchmarks: median dummy, Random Forest, tuned Extra Trees, XGBoost, LightGBM, and stacking.
- Outer validation: five independently shuffled 10-fold partitions.
- Uncertainty: one saved 5,000-replicate project-level bootstrap generated by NumPy PCG64 with seed `20260807`.
- Paired inference: project-mean Wilcoxon tests and a dependence-aware corrected repeated-cross-validation sensitivity, with Holm adjustment.

The empirical conclusions are conditioned on this 499-project dataset and should not be interpreted as evidence of universal superiority.

## Environment

The archived run used Python 3.9.6. Create either the Conda environment:

```bash
conda env create -f environment.yml
conda activate ijies-20265081-revision
```

or a Python virtual environment with the locked packages:

```bash
python3.9 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-lock.txt
```

On macOS, LightGBM and XGBoost may require an OpenMP runtime such as `libomp`.

## Verify the archived results

The fastest integrity check rehashes the dataset and every manifested artifact, recalculates all stored metrics from the out-of-fold predictions, verifies outer-fold coverage and the bootstrap matrix, and confirms that duplicated Global/Tuned Extra Trees prediction vectors have identical estimates and confidence intervals:

```bash
python verify_outputs.py \
  --run-dir outputs/revision_v1 \
  --config config.json
```

The expected status is `verified`. The verification performed for the submitted revision is archived in `verification_report_revision_v1.json`.

## Reproduce the complete analysis

Run the full reviewer-revision protocol from the repository root:

```bash
python run_analysis.py \
  --config config.json \
  --output-dir outputs/reproduced
```

The script verifies the dataset SHA-256 before fitting any model. It then saves exact outer-fold assignments, out-of-fold predictions, full-precision metrics, nested-tuning records, mutual-information selections, category diagnostics, paired tests, the shared bootstrap matrix, environment details, and artifact hashes.

The full run performs nested tuning and modern-model benchmarking, so runtime depends on the processor. For a short implementation check that is **not** suitable for manuscript reporting, use:

```bash
python run_analysis.py \
  --config config.json \
  --output-dir outputs/smoke \
  --smoke
```

## Reproducibility notes

- All preprocessing, thresholds, feature selection, hyperparameter tuning, category assignment, and model fitting are learned only from the relevant outer training partition.
- Fold-specific models are recreated by the script; separate pretrained weights are not needed.
- `outputs/revision_v1/bootstrap_project_indices.npy` is the single bootstrap index matrix reused for every manuscript model and metric.
- `outputs/revision_v1/run_manifest.json` contains SHA-256 hashes for the archived analysis artifacts.
- Smoke-test outputs must never be quoted as manuscript results.
